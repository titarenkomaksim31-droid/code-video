# code-video

Пакет учит делать видео, которого нет ни в одном файле: каждый кадр рисуется кодом, каждый звук синтезируется в момент воспроизведения, а на выходе получается один HTML и, если нужно, один MP4.

Три идеи, на которых держится всё остальное:

1. **Кадр — чистая функция времени.** `draw(t)` не помнит предыдущий кадр. Значит, любой момент можно отрендерить отдельно, а видео — собрать покадрово без записи экрана.
2. **Звук — партитура, а не файл.** Список событий `{t, type, ...}` читают и синтезатор, и таймлайн. Один источник правды — идеальная синхронизация.
3. **Один файл.** Ни картинок, ни шрифтов, ни mp3, ни CDN. Открывается двойным щелчком, живёт вечно, рендерится офлайн.

---

## Когда включать

- «сделай ролик / интро / заставку / титры / видео со звуком»;
- «html видео», «видео на canvas», «анимация с музыкой»;
- motion-графика, объясняющий ролик, промо на 15–90 секунд;
- 3D-сцена, которую надо отрендерить в файл.

**Не включать:** монтаж готового видео, работа с чужим mp4, субтитры к скачанному файлу, всё, где нужны реальные съёмки.

---

## Контракт страницы

Его понимают и рендерер, и человек, открывший файл.

```js
window.__meta = { title: 'Сигнал', width: 1920, height: 1080, fps: 30, duration: 24 };
window.__draw = (t) => render(t);   // t в секундах, 0 ≤ t ≤ duration
window.__ready = true;              // страница готова к покадровому рендеру
```

Требования к `render(t)`:

| Требование | Проверка |
|---|---|
| Никакого состояния между кадрами | Render t=5 дважды в разном порядке — пиксели совпадают |
| Никаких `Date.now()`, `performance.now()` | `grep -n "Date.now\|performance.now" file.html` пуст |
| Никакого `Math.random()` без сида | только `rng(seed)()` в фазах инициализации |
| Никакой сети | `grep -n "http" file.html` пуст (кроме комментариев) |

Если кадр зависит от предыдущего — покадровый рендер развалится, а перемотка будет врать. Это главная ошибка.

---

## Десять железных правил

1. **Один файл.** Всё внутрь: шрифты системные, картинки нарисованы, звук синтезирован.
2. **Кадр = f(t).** Никаких счётчиков, накоплений и «в прошлом кадре было…».
3. **Сид вместо случайности.** `mulberry32(seed)` в инициализации, результат в массив.
4. **Сетка BPM.** Всё на бит: 120 BPM → бит 0.5 с, такт 2 с, 16-я 0.125 с.
5. **Easing, не линейность.** Вход 4–8 кадров, 80 % пути за 30 % времени.
6. **Три плана глубины.** Фон, середина, передний план — разный контраст, резкость и скорость.
7. **Звук синтезируется.** Ни одного `new Audio('...mp3')`.
8. **Переход — событие на бите.** 6–12 кадров, звук поддерживает (райзер, импакт).
9. **Сначала кадры, потом рендер.** Контактный лист из 20 кадров дешевле, чем 3 минуты ffmpeg.
10. **Максимум 3 минуты и 8 глав.** Дольше — это уже не этюд, а проект с бюджетом.

## Процесс

### 0. Проверить среду

```bash
node -v
ffmpeg -version          # может отсутствовать — тогда путь через MediaRecorder
where chrome             # Windows: C:\Program Files\Google\Chrome\Application\chrome.exe
```

### 1. Бриф — не больше шести вопросов

Длительность · тема · тон (энергия/покой/драма) · формат (16:9 / 9:16) · звук (есть ли голос) · чем заканчивается.

Если пользователь не отвечает — придумать самому и сказать вслух: «взял 24 секунды, 120 BPM, неон-нуар, финал — белая вспышка».

### 2. Три концепта по одной строке

Обязательно разные: буквальный, метафора, жанровая пародия. Выбрать один, обосновать в одном предложении.

### 3. Раскадровка по барам

Таблица: сцена, время, бары, что на экране, что в звуке. 6–8 строк на 24 секунды.

| # | Время | Бары | Картинка | Звук |
|---|---|---|---|---|
| 1 | 0–6 | 0–2 | точка, линия, титр | пэд, саб-удар на 0 |
| 2 | 6–12 | 3–5 | горизонт, солнце | кик, бас, райзер к 6 |

### 4. Скелет

Скопировать [`assets/skeleton.html`](assets/skeleton.html), заменить сцены и партитуру. Он уже содержит: контракт, транспорт, Web Audio, офлайн-рендер звука в WAV, запись в WebM.

Проверка одного кадра в браузере: `skeleton.html?t=8`.

### 5. Сцены по одной

Одна сцена — один `function sceneX(t)`. Проверять кадр после каждой. Не писать четыре сцены вслепую.

### 6. Звук

Партитура — массив событий в том же файле. Сначала пэд и бас, потом ударные, потом эффекты.

### 7. Рендер

```bash
node scripts/render.mjs --html assets/skeleton.html --out out --fps 30
```

Скрипт сам: поднимает headless Chrome, рисует кадры, вытаскивает WAV через `OfflineAudioContext`, склеивает ffmpeg. Без ffmpeg — оставляет PNG и WAV.

### 8. QA

Контактный лист: `ffmpeg -i out.mp4 -vf "fps=2,scale=480:-1,tile=5x3" sheet.png`. Смотреть глазами, искать провалы, обрезанный текст, пустые кадры.

## Выбор техники

| Задача | Чем | Почему |
|---|---|---|
| Титры, графика, UI, спектр | Canvas 2D | быстрее всего писать, хватает на 90 % роликов |
| Глубина, камера, металл, стекло | Three.js | объём и материалы бесплатно |
| Огонь, вода, дым, искажения | WebGL-шейдер | попиксельно и дёшево |
| Ретро, пиксель-арт | Canvas 2D + палитра + дизеринг | ограничения дают стиль |
| Смешанно | 2D фон + 3D объект в углу | самый выигрышный вариант |

Правило: **3D только если есть камера или материал.** Кубик, вращающийся в пустоте, — хуже типографики.

## Минимальный рабочий пример

```html
<canvas id="c" width="1920" height="1080"></canvas>
<script>
const cv = document.getElementById('c'), ctx = cv.getContext('2d', { alpha: false });
const DUR = 8;

function drawText(text, x, y, o = {}) {
  ctx.save();
  ctx.font = `${o.weight || 900} ${o.size || 120}px "Segoe UI", system-ui, sans-serif`;
  ctx.textAlign = 'center'; ctx.textBaseline = 'middle';
  ctx.globalAlpha = o.alpha ?? 1; ctx.fillStyle = o.color || '#f4f7ff';
  ctx.fillText(text, x, y);
  ctx.restore();
}

function render(t) {
  const k = Math.min(1, Math.max(0, t / 1.2));           // вход
  const e = 1 - Math.pow(1 - k, 3);                       // easeOutCubic
  ctx.fillStyle = '#05060d'; ctx.fillRect(0, 0, 1920, 1080);
  ctx.globalAlpha = e;
  drawText('СИГНАЛ', 960, 540 - 30 * (1 - e), { alpha: e, size: 150 });
  ctx.globalAlpha = 1;
}

window.__meta = { title: 'Сигнал', width: 1920, height: 1080, fps: 30, duration: DUR };
window.__draw = render;
window.__ready = true;
render(0);
</script>
```

Восемь секунд, один титр, ноль зависимостей. Дальше наращивать сценами, эффектами и звуком.

## Анти-паттерны

| Что делает агент | Почему это мусор | Как надо |
|---|---|---|
| Тёмно-синий фон + неон + частицы «для атмосферы» | самый частый дефолт моделей, выглядит как заставка 2015 | выбрать один стиль из `03-visual-style.md` и держать его |
| Всё появляется одновременно | нет иерархии, глаз не знает, куда смотреть | stagger 40–80 мс, один ведущий элемент на кадр |
| Линейные анимации | движение мертвеца | easing из `02-timing-and-easing.md` |
| Текст поверх объектов | нечитаемо | подложка, тень, или пауза в движении фона |
| 40 секунд одной сцены | зритель уходит на 8-й | смена сцены каждые 3–6 с или развитие внутри сцены |
| Звук «просто фоном» | нет синхронизации | партитура из тех же событий, что и картинка |
| 20 тысяч частиц на canvas 2D | 8 fps | частицы на WebGL или 500–2000 на 2D |
| Готовый mp3 из интернета | ломает автономность | Web Audio синтез |

## Чек-лист перед сдачей

- [ ] Файл открывается двойным щелчком, звук стартует по кнопке.
- [ ] Нет внешних запросов: `http` в файле отсутствует.
- [ ] `render(t)` не использует время системы и случайность без сида.
- [ ] Длительность точно совпадает с `__meta.duration`.
- [ ] На каждом кадре есть смысловой центр.
- [ ] Текст читается на паузе: кегль ≥ 16 px, контраст ≥ 4.5:1.
- [ ] Звук не клиппит: пик ≤ −1 dB.
- [ ] Переходы попадают в бит.
- [ ] Контактный лист просмотрен, провалов нет.
- [ ] Рендер совпадает с превью.

---

## Тон общения

- Не задавать больше трёх вопросов подряд; остальное решать самому и озвучивать решение.
- Показывать кадр, а не описывать его словами.
- Предлагать два финала на выбор, а не один «правильный».
- Если пользователь просит «как у Claude» — не спорить, просто сделать хорошо.
