# Визуальный стиль code-video

Справочник для кадра 1920×1080, 30 fps (60 fps — только для быстрых сцен). Размеры даны в пикселях полного кадра; DPR не меняется, холст растягивается CSS. Стиль фиксируется до первого кадра: палитра, свет, композиция, текстура и порядок пост-обработки.

Контракт: `window.__draw(t)` — чистая функция от `t`; `window.__meta = {duration, fps, width, height, title}`; `window.__ready = true`. Внутри `draw` нет `Date.now()`, `performance.now()` и `Math.random()`; всё случайное создаётся при инициализации с сидом.

## Четыре стилевые системы

Паспорт — обязательный минимум для выбранной системы. Не смешивай две системы в одном ролике: смена допустима только на монтажной склейке в beat.

## Пять палитр

Доли — площадь крупных цветовых пятен, а не пиксели тонкого текста. Правило 60/30/10: 60% base, 30% support, 10% accent. Палитры 1–4 повторяют паспорта четырёх систем, пятая — дополнительный тёплый вариант.

### 1. «Ночной терминал» — неон-нуар, интерфейс

- 60% `#05060d` — фон, negative space, глубина.
- 24% `#0d1b2a` — плоскости, дальний план, туман.
- 6% `#4ff0ff` — key-графика, контуры, свечение.
- 7% `#ff3fa4` — контрудар, одна сцена на 4–8 c.
- 3% `#f4f7ff` — заголовок и блики, только по делу.

### 2. «Тёплая бумага» — редакционная графика

- 60% `#f2e8d5` — лист и negative space.
- 24% `#c9b79c` — тени бумаги, второй план, подложки.
- 6% `#1a1714` — основные массы туши и тело текста.
- 7% `#b23a2f` — печать, подчёркивание, одна метка на beat.
- 3% `#e8b04b` — маркерный блик, только на смысловом акценте.

### 3. «Фосфор» — ретро-CRT, телеметрия

- 60% `#04120b` — корпус и тёмные промежутки.
- 24% `#0a2a18` — свечение второго плана, сетка.
- 6% `#7dff9b` — основной сигнал и линии графика.
- 7% `#ffd166` — предупреждение, курсор, важная цифра.
- 3% `#e9ffe9` — пиковые блики и заголовок.

### 4. «Ледяное стекло» — свет и материал

- 60% `#081018` — глубина и фон.
- 24% `#14313c` — объём, преломление, мягкая тень.
- 6% `#8fe9ff` — холодный rim и внутреннее свечение.
- 7% `#ffd166` — тёплый key, конфликт температур.
- 3% `#ffffff` — спекуляр и тонкий текст.

### 5. «Аварийный янтарь» — тёмная сцена с теплом

- 60% `#0b0806` — фон и провалы.
- 24% `#2a170d` — дым, объём, дальний план.
- 6% `#ff7a18` — огонь и рабочий свет.
- 7% `#ffd166` — пиковый свет, заголовок, предупреждение.
- 3% `#f4f7ff` — холодный контрудар, чтобы кадр не стал монохромным.

## Свет: key, rim, fill

Порядок наложения: fill → key → rim → bloom. Свет должен иметь одно направление во всём кадре; исключение — практические источники внутри сцены.

| Источник | Где | Цвет | Сила | Приём в 2D |
|---|---|---|---|---|
| Key | верх-лево, вектор (-0.55, -0.8) | `#ffd166` | 10–22% | Линейный градиент по bbox объекта на 45–65% его длины; тёмная база остаётся. |
| Rim | сзади-справа, вектор (0.7, 0.5) | акцент палитры | 2–4 px, 70–100% | Смещённый силуэт под основным объектом или `stroke` 2–4 px по контуру. |
| Fill | низ-право, противоположно key | `#4ff0ff` | 6–14% | Радиальный градиент диаметром 1.2 диагонали; поднимает чёрный до `#05060d`. |

- Направленный градиент: `ctx.createLinearGradient(x, y, x + 0.55 * size, y + 0.8 * size)`, первый стоп — тёплый при 0.18–0.28 alpha, второй — прозрачный.
- Rim по контуру: залить силуэт акцентом, стереть его копию со сдвигом 2–3 px внутрь через `destination-out`; остаётся кромка. Дорого — не больше одного героя на кадр.
- Мягкая тень: направленное смещение 4–12 px, цвет тени — затемнённый fill, alpha 0.12–0.24; чёрная тень `rgba(0,0,0,0.5)` почти всегда выглядит грязно.
- Bloom — только по ярким пикселям: порог luma 0.72, downscale 1/4, сложение 0.25–0.4. Текст и мелкую UI-графику не блурим: читаемость важнее эффекта.
- Тёплые света и холодные тени: `screen` с янтарным радиальным градиентом 0.10–0.18; `multiply` с холодным градиентом `#36639e` 0.08–0.18 от теневой стороны. Второй градиент обязательно прозрачен в зоне key.

## Композиция

Safe area 5%: 96 px по бокам и 54 px сверху/снизу. Рабочая зона — x 96…1824, y 54…1026. Всё, что выходит за неё, может быть обрезано плеером.

| Область | Значение | Как использовать |
|---|---|---|
| Нижняя треть | y 720…1026 | Титры: x 96…1400, кегль 96–118 px, 2 строки, базовая линия 900–960, подпись на 32 px ниже. |
| Оптический центр | (960, 505) | Выше геометрического (960, 540) на 35 px; сюда ставится герой или главный объект. |
| Сетка третей | x 640 / 1280, y 360 / 720 | Пересечение — точка входа взгляда; занимай одно пересечение, не четыре. |
| Negative space | 35–50% площади | Одна чистая сторона кадра; фон без мелких деталей, чтобы работал контраст. |
| Поля | 5% | Фон продолжается под титрами, но значимые объекты не входят в поля. |

Три плана глубины различаются не только размером. Дальний план приглушается и уходит в фон, передний — быстрее в параллаксе; резкость и контраст задают порядок чтения. Минимальный кегль 48 px; всё мельче — необязательная графика без смысловой нагрузки.

| План | Контраст | Резкость | Параллакс | Насыщенность | Содержимое |
|---|---|---|---|---|---|
| Дальний | 30–50% | blur 4–9 px | 0.15–0.3× | 50–70% | Небо, туман, сетка, подложка; подмешать фон на 25–40%. |
| Средний | 65–85% | 0–1 px | 0.4–0.7× | 85–100% | Герой и основное действие; фокус всегда здесь. |
| Передний | 90–100% | blur 2–7 px или 0 | 1.2–1.8× | 60–85% | Силуэт, рамка, ветка, блик; занимает 8–20% кадра. |

## Текстура

| Эффект | Параметр | Как накладывать |
|---|---|---|
| Зерно | 3–6% alpha | Три тайла 256×256, `overlay`, детерминированный сдвиг каждый кадр. На MP4 ставь 5–6%, иначе кодек съест шум. |
| Сканлайны | период 2–4 px | Тёмная линия 1–2 px, 6–16% alpha; выравнивай по чётным координатам, иначе муар. |
| Виньетка | 25–60% | Радиальный градиент: прозрачно до 45–65% радиуса, затем затемнение до 0.25–0.60 на краю. |
| Halation | blur 12–30 px | Только по пикселям с luma > 0.8; тёплый оттенок, 8–18% alpha, `screen`. |

Текстура — последний слой перед титрами. Сканлайны и зерно поверх текста снижают читаемость: выноси HUD и заголовок после них или применяй эффект к отдельной области сцены.

## Грейдинг в canvas

Lift/gamma/gain по каналам: `out = pow(clamp(in * (gain - lift) + lift, 0, 1), 1 / gamma)`. Рабочие диапазоны: lift 0…0.05, gamma 0.9…1.15, gain 0.9…1.1. В canvas это быстрый LUT на 256 значений на канал; полный `getImageData` на 1920×1080 стоит 12–30 мс и только для пост-обработки.

| Стиль | Lift RGB | Gamma | Gain RGB |
|---|---|---|---|
| Неон-нуар | 0.004, 0.008, 0.018 | 1.08 | 1.02, 0.98, 1.00 |
| Бумага и тушь | 0.018, 0.016, 0.012 | 0.98 | 1.02, 1.00, 0.96 |
| Ретро-CRT | 0.010, 0.020, 0.010 | 1.06 | 0.98, 1.04, 0.97 |
| Стекло и свет | 0.010, 0.014, 0.020 | 1.04 | 0.98, 1.00, 1.03 |

Слои композитинга:

- `multiply` цветом палитры при 8–20% alpha уплотняет тени; не превышай 20%, иначе белый текст сереет.
- `overlay` акцентом 6–12% даёт контраст в средних тонах; нейтральный серый не меняет кадр, цветной — тонирует.
- `screen` янтарным радиальным градиентом 10–18% — тёплый key; `multiply` холодным градиентом 8–18% с теневой стороны — холодные тени.
- Грейдинг выполняется один раз после сцены и эффектов, до зерна и текста. Он разрушает холст, поэтому каждый кадр начинается с чистой перерисовки.

## Ошибки-клише

| Клише | Почему ломает кадр | Замена |
|---|---|---|
| Тёмно-синий + неон + частицы | Нулевая иерархия, всё светится одинаково | Один акцент, тёмная база, зерно и направленный key |
| Всё в центре | Нет движения взгляда, титры спорят с героем | Одно пересечение третей, negative space 35–50% |
| Радужные градиенты | Нет доминанты, цвет не несёт смысла | База + два оттенка; переход только между соседними по теплоте |
| Тени по умолчанию | `shadowBlur` без направления даёт грязный ореол | Смещение 4–12 px, цвет тени от fill, alpha 0.12–0.24 |
| Стоковые «tech» линии | Сетки и гексы не связаны с содержанием | Геометрия из данных: одна ось, реальные числа, 3% служебных меток |

## Сниппет: палитра и grade()

Вызов — после сцены и эффектов, один раз за кадр. `t` используется только для дыхания света в 2 c (один bar при 120 BPM), поэтому функция остаётся детерминированной.

```js
const PALETTE = Object.freeze({
  bg: '#05060d',
  ink: '#f4f7ff',
  cyan: '#4ff0ff',
  magenta: '#ff3fa4',
  amber: '#ffd166',
});

const BEAT = 0.5; // 120 BPM
const BAR = BEAT * 4; // 2 c

function grade(ctx, t) {
  const w = ctx.canvas.width;
  const h = ctx.canvas.height;
  const pulse = 0.12 + 0.025 * Math.sin((2 * Math.PI * t) / BAR);

  ctx.save();

  // Проход 1: тёплый key сверху слева.
  ctx.globalCompositeOperation = 'screen';
  const key = ctx.createRadialGradient(
    w * 0.26, h * 0.16, 0,
    w * 0.26, h * 0.16, w * 0.78
  );
  key.addColorStop(0, `rgba(255, 209, 102, ${pulse})`);
  key.addColorStop(0.45, 'rgba(255, 209, 102, 0.045)');
  key.addColorStop(1, 'rgba(255, 209, 102, 0)');
  ctx.fillStyle = key;
  ctx.fillRect(0, 0, w, h);

  // Проход 1: холодные тени с противоположной стороны.
  ctx.globalCompositeOperation = 'multiply';
  const cool = ctx.createLinearGradient(0, h, w, 0);
  cool.addColorStop(0, 'rgba(42, 86, 138, 0.28)');
  cool.addColorStop(0.5, 'rgba(42, 86, 138, 0.10)');
  cool.addColorStop(1, 'rgba(42, 86, 138, 0)');
  ctx.fillStyle = cool;
  ctx.fillRect(0, 0, w, h);

  // Проход 2: overlay-контраст и виньетка 38%.
  ctx.globalCompositeOperation = 'overlay';
  ctx.fillStyle = 'rgba(24, 36, 58, 0.10)';
  ctx.fillRect(0, 0, w, h);

  ctx.globalCompositeOperation = 'source-over';
  const vig = ctx.createRadialGradient(
    w / 2, h * 0.47, h * 0.30,
    w / 2, h * 0.47, h * 0.78
  );
  vig.addColorStop(0, 'rgba(5, 6, 13, 0)');
  vig.addColorStop(0.68, 'rgba(5, 6, 13, 0.10)');
  vig.addColorStop(1, 'rgba(5, 6, 13, 0.38)');
  ctx.fillStyle = vig;
  ctx.fillRect(0, 0, w, h);

  ctx.restore();
}
```
