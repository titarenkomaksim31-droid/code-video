# 10. QA: приёмка ролика до и после рендера

Проверки идут в два прохода: до рендера — по коду и по одному кадру, после — по файлу и по контактному листу. Всё, что ловится до рендера, стоит 10 секунд; то же после — 4 минуты пересборки.

## 10.1 Чек-лист перед рендером (10 пунктов)

1. **Детерминизм.** `__draw(12.345)` дважды подряд даёт одинаковый PNG. В странице нет `Date.now()`, `performance.now()`, `Math.random()` без сида и полей, которые переживают кадр.

   ```bash
   node -e "const h=require('crypto').createHash('md5');const f=require('fs');for(const n of ['f_00370.png','f_00371.png'])h.update(f.readFileSync('frames/'+n));console.log(h.digest('hex'))"
   ```

   Прогнать рендер дважды на 3 кадра и сравнить хеши. Разошлись — искать состояние.

2. **Нет внешних файлов.** В HTML не должно быть ни одной сетевой или файловой зависимости:

   ```bash
   findstr /n /r /c:"http" /c:"<img" /c:"@font-face" /c:"url(" /c:"fetch(" /c:"new Audio" index.html
   ```

   Пустой вывод — норма. Шрифт только `system-ui, "Segoe UI", sans-serif`, картинки — только код.

3. **Длительность.** `__meta.duration` в диапазоне 20–90 с, число кадров `Math.round(duration * fps)` целое и совпадает с тем, что ждёт ffmpeg.

4. **fps.** `__meta.fps` — 30 или 60, совпадает с `-framerate` в команде ffmpeg и с `-r` на выходе. Смешивать нельзя.

5. **Тишина в начале.** Первые 0.3 с — тишина: ни пэда, ни реверберационного хвоста. Проверка после рендера даёт `max_volume ≤ -50 dB` на этом окне.

6. **Пики.** Ни один сэмпл не выше −1 dBFS до кодека. Пик считается по сумме всех источников, а не по каждому отдельно: бас + кик + пэд легко дают 1.4.

7. **Safe area.** Весь текст внутри прямоугольника `x ∈ [96, 1824]`, `y ∈ [54, 1026]`. Нижняя треть до `y = 900` — если планируются субтитры.

8. **Читаемость.** Минимальный кегль 48 px при 1920×1080, заголовки 96–180 px, межстрочный 1.2–1.3. Строка длиннее 1728 px — обрезается или переносится.

9. **Палитра.** Используются только `#05060d`, `#4ff0ff`, `#ff3fa4`, `#ffd166`, `#f4f7ff` и их прозрачности. Посторонний оттенок ломает единство глав.

10. **Конечность.** `__draw(0)`, `__draw(duration)` и `__draw(duration - 1e-6)` не дают `NaN` в координатах. Проверка в консоли:

    ```js
    // вставлять в консоль после загрузки страницы
    for (const t of [0, 0.001, __meta.duration - 1e-6, __meta.duration]) {
      __draw(t);
      const d = document.querySelector('canvas').getContext('2d').getImageData(0, 0, 1, 1).data;
      if (d[3] !== 255) console.warn('кадр не залит при t =', t);
    }
    ```

## 10.2 Чек-лист после рендера (10 пунктов)

1. **Длительность ±1 кадр.** Видео `90.000 ± 0.034` при 30 fps. Аудио в тех же пределах ±0.010.
2. **Число кадров.** `nb_frames == Math.round(duration * fps)`. Меньше — ffmpeg съел кадры на склейке.
3. **CFR.** `r_frame_rate == avg_frame_rate == 30/1`. Расхождение — переменный фреймрейт.
4. **Звук есть.** Поток `aac`, 48000 Гц, 2 канала, длительность равна видео.
5. **Нет клиппинга.** `max_volume ≤ -1.0 dB`, `flat factor < 10`.
6. **Первый кадр.** Не чёрный: `YAVG > 30` в шкале 16–235, то есть средняя яркость > 0.06.
7. **Последний кадр.** Содержит финальный текст/объект, не пустой, не чёрный.
8. **Нет залипаний.** `freezedetect` не находит статики дольше 2.0 с вне запланированных пауз.
9. **Плотность монтажа.** Смен сцены не больше `duration / 1.5`; для 90 с — не больше 60.
10. **Файл целый.** `ffmpeg -v error -i out.mp4 -f null -` молчит, размер 8–60 МБ на 90 с при CRF 18.

## 10.3 Как смотреть контактный лист

```bash
ffmpeg -y -i out.mp4 -vf "fps=2,scale=480:-1,tile=5x3" -fps_mode vfr sheets/s_%02d.png
```

2 кадра в секунду — 15 плиток на лист, лист покрывает 7.5 с, для 90 с это 12 листов. Смотреть слева направо, сверху вниз, лист за листом.

Что искать:

| Признак | Что значит |
|---|---|
| Две соседние плитки идентичны | анимация застыла: нет движения или `t` не растёт |
| Плитки резко разной яркости через одну | мигание, сцена дёргает экспозицию |
| Пустая плитка в середине | провал между главами, забытый `if (t < ...)` |
| Текст прижат к краю | вылет из safe area, обрезка на телефоне |
| Все плитки одинаково тёмные | средняя яркость ниже 0.15, ролик «проваливается» |
| Одна плитка полностью чёрная | кадр-дырка: сцена закончилась раньше времени |
| Плитки с «лесенкой» на диагоналях | включён `imageSmoothingEnabled = false` или рендер в половинном разрешении |

Порядковый номер листа × 7.5 с = время первой плитки. Дальше уточнять `ffmpeg -ss <t> -i out.mp4 -frames:v 1 probe.png`.

## 10.4 Таблица дефектов

| Симптом | Причина | Фикс |
|---|---|---|
| Анимация дёргается, рывки на равномерном движении | `__draw` зависит от предыдущего кадра или от часов | только `t`, позиция `= f(t)`; двойной прогон и сравнение хешей |
| Звук уходит вперёд картинки к концу | WAV записан MediaRecorder в реальном времени | `OfflineAudioContext`, длина ровно `duration * 48000` |
| Текст обрезан справа | ширина строки > 1728 px | `measureText` + перенос по словам, `maxWidth = 1728` |
| Сцена пустая 1–2 с | пауза между главами без события | HUD/счётчик/линия живут всегда, паузу сократить до 1 с |
| Цвета бледные, циан уходит в зелёный | RGB→YUV по BT.601, теги BT.709 | `scale=out_color_matrix=bt709` + `-colorspace bt709 -color_primaries bt709 -color_trc bt709` |
| Клиппинг на пиках, хрип | сумма источников > 1.0 | `master.gain = 0.7`, компрессор `threshold -12, ratio 4` |
| Чёрный кадр в начале | снимок до `document.fonts.ready` | ждать `__ready`, затем `fonts.ready`, потом `__draw(0)` |
| Дрожание шрифта между кадрами | координаты текста дробные | `Math.round(x)`, `Math.round(y)`, `--font-render-hinting=none` |
| Дропнутые кадры, «строб» | VFR во входе | `-fps_mode cfr -r 30` |
| Слишком быстрый монтаж | смена сцены чаще 1.5 с | слить сцены, оставить 10–15 смен на 90 с |
| Видео короче звука на 0.2–0.5 с | `Math.floor` в подсчёте кадров | `Math.round`, `-shortest` |
| Постоянный гул 50 Гц | незакрытый `OscillatorNode`, DC offset | `stop(t)`, `highpass 30 Гц` на мастере |
| Дубли кадров на медленном движении | шаг движения меньше 1 px | амплитуду ×2 или subpixel через `translate` |
| Бандинг на градиенте | `yuv420p` + CRF 20 | CRF 16–18, шум 1–2 LSB от сида по `t` |
| Финальный кадр пустой | цикл `f <= total` | `f < total`, последний `t = (total - 1) / fps` |

## 10.5 Числовые пороги

| Метрика | Норма | Как мерить |
|---|---|---|
| Средняя яркость кадра | 0.15–0.45 | `signalstats` → `YAVG`, потом `(YAVG - 16) / 219` |
| Контраст кадра | `YMAX - YMIN ≥ 120` | тот же `signalstats` |
| Движение | 2–8 % пикселей за кадр | `tblend=difference` + `blackframe`, `100 - pblack` |
| Плотность монтажа | смена сцены не чаще 1.5 с | `select='gt(scene,0.25)'` |
| True peak | ≤ −1 dBTP | `ebur128=peak=true` |
| Громкость | −16…−12 LUFS | `ebur128`, строка `I:` |
| Тишина в начале | ≤ −50 dB на 0–0.3 с | `atrim=0:0.3,volumedetect` |
| Кегль текста | ≥ 48 px | `auditText` до рендера |
| Строка текста | ≤ 1728 px | `measureText` |
| Размер файла | 8–60 МБ / 90 с | `ffprobe format=size` |

```bash
# яркость и контраст по кадрам
ffmpeg -v error -i out.mp4 -vf "signalstats,metadata=print:key=lavfi.signalstats.YAVG:file=-" -f null -

# доля изменившихся пикселей (движение = 100 - pblack)
ffmpeg -v info -i out.mp4 -vf "tblend=all_mode=difference,blackframe=amount=0:threshold=12" -f null - 2>&1 | findstr pblack

# статика дольше 1.5 с
ffmpeg -v info -i out.mp4 -vf "freezedetect=n=-60dB:d=1.5" -f null - 2>&1 | findstr freeze_start
```

Порог 0.15–0.45 считается по линейной яркости: тёмный фон `#05060d` даёт 0.02, и если 80 % кадра — фон, средняя упадёт до 0.08. Лечится не поднятием фона, а площадью светлых элементов: HUD, крупный текст, свечение.

## 10.6 Звук

- **True peak ≤ −1 dBTP.** Между пиком WAV и пиком после AAC-кодека разница до 0.4 дБ: оставлять запас 1 дБ, а не 0.1.
- **Тишина в первые 0.3 с.** Старт с нуля, без fade-in пэда: зритель должен услышать удар, а не нарастание.
- **Постоянный гул.** Любой `OscillatorNode` без `stop()` гудит до конца файла. Проверка: `astats` → `DC offset` < 0.001, `flat factor` < 10.
- **Хвост реверба.** `ConvolverNode`/`DelayNode` тянет звук за `duration`: обрезать `master.gain.setValueAtTime(0, duration - 0.05)` с рампой 50 мс, иначе `-shortest` съест последний кадр видео.
- **Моно-совместимость.** Проверить сумму каналов: фазовый рассинхрон даёт провал баса в моно.

```bash
ffmpeg -v info -i out.mp4 -af "ebur128=peak=true" -f null - 2>&1 | findstr /r "I: Peak:"
ffmpeg -v error -i out.mp4 -af "astats=metadata=1:reset=0" -f null - 2>&1 | findstr /r "Peak level dB Flat factor DC offset"
```

Целевые значения: `I: -14.0 LUFS`, `Peak: -1.2 dBFS`, `Flat factor: 0.000000`.

## 10.7 Текст

Орфография и типографика — до рендера, потому что исправление после стоит полной пересборки.

```js
// Прогон строк ролика через правила; возвращает список нарушений
const RULES = [
  [/ {2,}/, 'двойной пробел'],
  [/\s+[.,;:!?]/, 'пробел перед знаком'],
  [/(^|\s)-(\s|$)/, 'дефис вместо тире'],
  [/"/, 'прямые кавычки вместо «»'],
  [/\b(чтоб|щас|ваще|типа)\b/, 'разговорная форма'],
  [/[A-ZА-Я]{4,}/, 'капс длиннее 3 букв'],
];
const auditString = s => RULES.filter(([re]) => re.test(s)).map(([, m]) => m);
```

Проверка вёрстки в самом canvas до запуска рендера:

```js
// Вызывать после fonts.ready, на том же ctx, что и рендер
function auditText(ctx, items) {
  const bad = [], L = 96, R = 1824, T = 54, B = 1026;
  for (const it of items) {
    ctx.font = `${it.weight || 600} ${it.size}px system-ui, "Segoe UI", sans-serif`;
    const w = ctx.measureText(it.text).width;
    if (it.size < 48) bad.push(`кегль ${it.size}: ${it.text}`);
    if (w > 1728) bad.push(`строка ${Math.round(w)} px: ${it.text}`);
    if (it.x < L || it.x + w > R) bad.push(`вылет по X: ${it.text}`);
    if (it.y < T || it.y > B) bad.push(`вылет по Y: ${it.text}`);
  }
  return bad;                              // пустой массив = можно рендерить
}
```

Размеры для 1920×1080:

| Роль | Кегль | Вес | Межстрочный |
|---|---|---|---|
| Заголовок главы | 120–180 | 700 | 1.05 |
| Подзаголовок | 72–96 | 600 | 1.2 |
| Основной текст | 56–72 | 500 | 1.3 |
| Подпись, HUD | 44–56 | 500 | 1.2 |
| Моно-код | 44–56 | 400 | 1.4 |

Правила переноса: не больше 2 строк в заголовке и 3 в подзаголовке; перенос только по словам, никогда по слогам; висячий предлог в конце строки — переставить. Проверка «читается ли» — уменьшить превью до 480 px по ширине: если строку нельзя прочитать, кегль мал.

## 10.8 Автоматический прогон

Один скрипт закрывает пункты 10.2.1–10.2.5 и 10.5. Нужен `ffprobe` в `PATH`.

```js
// qa.js — node qa.js out.mp4 90 30
const { spawnSync } = require('node:child_process');
const [file, durArg, fpsArg] = process.argv.slice(2);
const D = Number(durArg), FPS = Number(fpsArg || 30), FRAMES = Math.round(D * FPS);
let fail = 0;
const check = (name, ok, got) => {
  if (!ok) fail++;
  console.log(`${ok ? 'OK  ' : 'FAIL'}  ${name}: ${got}`);
};
const run = (bin, args) => spawnSync(bin, args, { encoding: 'utf8' });

const probe = JSON.parse(run('ffprobe', [
  '-v', 'error', '-print_format', 'json', '-show_format', '-show_streams', file,
]).stdout);
const v = probe.streams.find(s => s.codec_type === 'video');
const a = probe.streams.find(s => s.codec_type === 'audio');

check('длительность видео', Math.abs(+v.duration - D) <= 1 / FPS + 0.002, `${v.duration} с`);
check('число кадров', +v.nb_frames === FRAMES, `${v.nb_frames} из ${FRAMES}`);
check('CFR', v.r_frame_rate === v.avg_frame_rate, `${v.r_frame_rate} / ${v.avg_frame_rate}`);
check('разрешение', v.width === 1920 && v.height === 1080, `${v.width}x${v.height}`);
check('дорожка', !!a && +a.sample_rate === 48000 && a.channels === 2,
  a ? `${a.codec_name} ${a.sample_rate} Гц / ${a.channels}` : 'нет');
check('длительность аудио', !!a && Math.abs(+a.duration - +v.duration) < 0.02,
  a ? `${a.duration} с` : 'нет потока');
check('размер', +probe.format.size > 8e6 && +probe.format.size < 60e6,
  `${(probe.format.size / 1e6).toFixed(1)} МБ`);

// true peak и интегральная громкость
const loud = run('ffmpeg', ['-v', 'info', '-i', file, '-af', 'ebur128=peak=true', '-f', 'null', '-']).stderr;
const peak = +(loud.match(/Peak:\s+(-?\d+\.\d+)/) || [])[1];
const lufs = +(loud.match(/I:\s+(-?\d+\.\d+) LUFS/) || [])[1];
check('true peak', peak <= -1.0, `${peak} dBFS`);
check('громкость', lufs >= -16 && lufs <= -12, `${lufs} LUFS`);

// средняя яркость по всем кадрам
const stats = run('ffmpeg', ['-v', 'error', '-i', file, '-vf',
  'signalstats,metadata=print:key=lavfi.signalstats.YAVG:file=-', '-f', 'null', '-']).stdout;
const y = [...stats.matchAll(/YAVG=([\d.]+)/g)].map(m => +m[1]);
const lum = (y.reduce((s, x) => s + x, 0) / y.length - 16) / 219;
check('яркость', lum >= 0.15 && lum <= 0.45, lum.toFixed(3));
check('чёрные кадры', Math.min(...y) > 16, `YMIN ${Math.min(...y).toFixed(1)}`);

console.log(fail ? `\n${fail} проверок не прошло — пересобирать` : '\nвсе проверки прошли');
process.exit(fail ? 1 : 0);
```

Типичный вывод:

```text
OK    длительность видео: 90.000000 с
OK    число кадров: 2700 из 2700
OK    CFR: 30/1 / 30/1
OK    разрешение: 1920x1080
OK    дорожка: aac 48000 Гц / 2
FAIL  true peak: -0.4 dBFS
OK    громкость: -14.1 LUFS
OK    яркость: 0.271
```

`FAIL` по пику лечится `master.gain 0.7` и пересборкой — не нормализацией готового файла: AAC уже срезал вершины.

Что скрипт не проверяет и смотреть глазами: композицию, обрезанный текст, смысл кадра, ритм монтажа. Это контактный лист из 10.3 и полный просмотр с начала до конца.
