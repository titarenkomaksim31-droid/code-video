# 11. Длинный формат: 60–180 секунд

До 20 с ролик держится одним приёмом. После 60 с приёмов нужно 4–6, и они должны быть связаны: зритель запоминает не кадры, а структуру. Формат ниже рассчитан на 1920×1080, 30 fps, BPM 120 (beat 0.5 с, bar 2 с, 16-я 0.125 с).

## 11.1 Структура

| Секция | Время | Бары | Задача | Провал, если |
|---|---|---|---|---|
| Хук | 0.0–3.0 | 0–1.5 | кадр уже движется, текст уже есть | первые 0.5 с без движения |
| Тезис | 3.0–10.0 | 1.5–5 | одно предложение: что зритель получит | текст длиннее 12 слов |
| Глава 1 | 10.0–27.0 | 5–13.5 | первая мысль, самый плотный монтаж | 3 идеи в одной главе |
| Глава 2 | 27.0–44.0 | 13.5–22 | вторая мысль, новый визуальный язык | та же композиция, что в гл. 1 |
| Дыхание | 44.0–45.5 | 22–22.75 | пауза 1.5 с, звук в ноль | паузы нет |
| Глава 3 | 45.5–61.0 | 22.75–30.5 | третья мысль, глубина | глава копирует главу 1 |
| Глава 4 | 61.0–76.5 | 30.5–38.25 | поворот: цифра, контраст, слом | глава повторяет главу 2 |
| Дыхание | 76.5–78.0 | 38.25–39 | вторая пауза перед callback | сразу в callback |
| Callback | 78.0–85.0 | 39–42.5 | кадр из хука с новым смыслом | забыли хук |
| Финал | 85.0–90.0 | 42.5–45 | один кадр, титр, затухание | обрыв на полуслове |

Арифметика: `3 + 7 + Σглав + 1.5×(пауз) + 7 + 5 = duration`. Для 90 с — четыре главы: 17 + 17 + 15.5 + 15.5 и две паузы. Для 60 с — три главы по 12.2 с и одна пауза. Для 180 с — восемь глав по 19.2 с и три паузы: это предел, дальше главы уходят ниже 12 с.

Правила хука:

- Первый кадр — уже композиция: объект в движении, крупный текст, звук с 0.0 с.
- Первый смысловой текст появляется на 0.2–0.4 с, не позже.
- Никаких логотипов, заставок, «сейчас будет».
- Один удар в 0.0 с и второй на 0.5 с (beat 1) — вход в ритм.

Тезис — одна строка, 2 строки максимума, 8–12 слов, кегль 96–120 px. Он же задаёт обещание, которое callback закрывает.

## 11.2 Карта темпа

Плотность — число визуальных событий в секунду (появление объекта, смена цвета, удар текста).

| Секция | Время | Бары | Событий/с | Картинка | Звук |
|---|---|---|---|---|---|
| Хук | 0–3 | 0–1.5 | 4–6 | удар, зум 1.25→1.0, инверсия фона | impact + sub drop |
| Тезис | 3–10 | 1.5–5 | 1.5–2 | текст по словам, фон 4 % | пэд, без ударных |
| Глава 1 | 10–27 | 5–13.5 | 2–3 | таймлайн, 6 узлов | kick 4/4 + hat 8-е |
| Глава 2 | 27–44 | 13.5–22 | 2.5–3 | волна, спектр, сетка | kick + clap на 2 и 4 |
| Дыхание | 44–45.5 | 22–22.75 | 0–0.5 | статика, 2 px дрейф | тишина −∞ |
| Глава 3 | 45.5–61 | 22.75–30.5 | 2–3 | глубина, параллакс | kick + арпеджио 16-е |
| Глава 4 | 61–76.5 | 30.5–38.25 | 3–4 | слом: другая палитра | смена тембра, что-то ломается |
| Дыхание | 76.5–78 | 38.25–39 | 0–0.5 | один объект, тёмный фон | пэд −18 дБ |
| Callback | 78–85 | 39–42.5 | 1.5 | кадр хука, новый текст | пэд + один impact |
| Финал | 85–90 | 42.5–45 | 0.5 | титр, затухание | финальный аккорд, хвост 1.5 с |

Правило: пик плотности — глава 4, не хук. Хук плотный по контрасту, а не по количеству событий.

Сетка времени в коде:

```js
const BPM = 120, BEAT = 60 / BPM, BAR = 4 * BEAT;   // 0.5 и 2.0
const PALETTE = { bg: '#05060d', cyan: '#4ff0ff', magenta: '#ff3fa4',
                  amber: '#ffd166', white: '#f4f7ff' };
const q = (t, step = 0.125) => Math.round(t / step) * step;   // привязка к 16-й
const inBar = t => (t % BAR) / BAR;                  // 0..1 внутри такта
const beatIdx = t => Math.floor(t / BEAT);
```

Границы сцен не пишутся руками, а считаются из длительностей: правка одной цифры переставляет всё дальше.

```js
// План 90 с: пары [id, длина]. Границы вычисляются накопительно
const PLAN = [
  ['hook', 3], ['thesis', 7], ['c1', 17], ['c2', 17], ['breath', 1.5],
  ['c3', 15.5], ['c4', 15.5], ['breath', 1.5], ['callback', 7], ['finale', 5],
];
const TIMELINE = (() => {
  let acc = 0;
  return PLAN.map(([id, d]) => { const s = { id, t0: acc, t1: acc + d }; acc += d; return s; });
})();
const CHAPTERS = TIMELINE.filter(s => /^c\d$/.test(s.id));      // 4 главы
console.assert(Math.abs(TIMELINE.at(-1).t1 - 90) < 1e-6, 'план не сходится к duration');
```

## 11.3 Скрипт как данные

Ролик длиннее 30 с пишется не в коде, а в `SCRIPT.md`: таблица, которую можно править без пересборки логики. Пять колонок, время в секундах, конец секции = начало следующей.

```md
| scene | time | text | action | sound |
|---|---|---|---|---|
| hook | 0.0–3.0 | ОДИН ФАЙЛ. | slam-in, zoom 1.25→1.0 | impact −6 дБ |
| thesis | 3.0–10.0 | 1920×1080, без ассетов. | слова по 0.08 с, фон 4 % | pad in 2 бара |
| c1 | 10.0–27.0 | три пути к файлу | линия-таймлайн, 6 узлов | kick 4/4, hat 8-е |
| c2 | 27.0–44.0 | звук считается отдельно | волна + спектр | kick + clap 2/4 |
| breath | 44.0–45.5 | — | статика, дрейф 2 px | тишина |
```

Правила заполнения:

- `scene` — одно из `hook | thesis | c1..c6 | breath | callback | finale`.
- `time` — `a–b`, всегда с точкой, конец секции совпадает с началом следующей.
- `text` — то, что реально попадает в кадр, дословно; `—` если текста нет.
- `action` — что меняется на экране, глагол + объект.
- `sound` — инструмент + ритм, без громкости в dB (громкость живёт в миксе).

Парсер в массив сцен:

```js
// parseScript.js — SCRIPT.md → сцены; никаких зависимостей
function parseScript(md) {
  return md.split('\n')
    .filter(l => /^\|\s*(hook|thesis|c\d|breath|callback|finale)\s*\|/.test(l))
    .map(l => l.split('|').slice(1, -1).map(s => s.trim()))
    .map(([scene, time, text, action, sound]) => {
      const [a, b] = time.split(/[–—-]/).map(Number);
      return { scene, t0: a, t1: b, text, action, sound };
    })
    .sort((x, y) => x.t0 - y.t0);
}

const SCENES = parseScript(SCRIPT_MD);
const RENDER = {
  hook: drawHook, thesis: drawThesis, c1: drawTimeline, c2: drawWave,
  breath: drawBreath, c3: drawDepth, c4: drawBreak,
  callback: drawCallback, finale: drawFinale,
};
const sceneAt = t => SCENES.find(s => t >= s.t0 && t < s.t1) || SCENES[SCENES.length - 1];

// Стыки без дыр, сумма = duration, глав не больше 8
function validateScript(list, duration) {
  const err = [];
  if (list[0].t0 !== 0) err.push('первая сцена не с 0');
  for (let i = 1; i < list.length; i++) {
    if (Math.abs(list[i].t0 - list[i - 1].t1) > 1e-6) {
      err.push(`стык ${list[i - 1].scene} → ${list[i].scene}: ${list[i - 1].t1} ≠ ${list[i].t0}`);
    }
  }
  const last = list.at(-1);
  if (Math.abs(last.t1 - duration) > 1e-6) err.push(`конец ${last.t1} ≠ ${duration}`);
  const ch = list.filter(s => /^c\d$/.test(s.scene)).length;
  if (ch > 8) err.push(`глав ${ch}, максимум 8`);
  if (!list.some(s => s.scene === 'hook' && s.t1 - s.t0 <= 3)) err.push('хук длиннее 3 с');
  return err;                                  // пустой массив = таблица валидна
}
const problems = validateScript(SCENES, window.__meta.duration);
if (problems.length) throw new Error(problems.join('; '));

// Единственная точка входа кадра: сцена получает локальное время
function draw(t) {
  const s = sceneAt(t);
  ctx.save();
  RENDER[s.scene](t - s.t0, t, s.t1 - s.t0);   // (локальное, глобальное, длина)
  ctx.restore();
  drawHUD(ctx, t);
}
window.__draw = draw;                        // контракт кадра: чистая функция t
```

## 11.4 Повторяющиеся элементы

Связность держится на 2–3 объектах, которые есть в каждом кадре и меняются вместе с главами.

| Элемент | Где | Правило |
|---|---|---|
| HUD-счётчик `01 / 06` | левый верхний угол, x 96, y 72 | mono 44 px, alpha 0.35, номер главы |
| Линия прогресса | y 1042, 2 px, от 96 до 1824 | ширина `= (t / duration) * 1728` |
| Точка-маркер | перелетает по траектории главы | всегда одна, 12 px радиус, цвет главы |
| Время-код `00:42` | правый верхний угол | обновляется раз в 0.25 с, не каждый кадр |

```js
// HUD рисуется последним и не зависит от сцены
function drawHUD(ctx, t) {
  const idx = SCENES.filter(s => s.t0 <= t).length;
  ctx.save();
  ctx.globalAlpha = 0.35;
  ctx.fillStyle = PALETTE.white;
  ctx.font = '400 44px ui-monospace, Consolas, monospace';
  ctx.textBaseline = 'top';
  ctx.fillText(`${String(idx).padStart(2, '0')} / ${String(CHAPTERS.length).padStart(2, '0')}`, 96, 54);
  ctx.textAlign = 'right';
  ctx.fillText(fmt(t), 1824, 54);
  ctx.globalAlpha = 1;
  ctx.fillStyle = accentAt(t);                 // цвет текущей главы
  ctx.fillRect(96, 1042, 1728 * (t / window.__meta.duration), 2);
  ctx.restore();
}
const fmt = s => `${String(Math.floor(s / 60)).padStart(2, '0')}:${String(Math.floor(s % 60)).padStart(2, '0')}`;
```

Счётчик не перерисовывается чаще 4 раз в секунду — иначе на 30 fps он «дрожит» субпикселями.

## 11.5 Переходы между главами

| Тип | Длительность | Когда | Код |
|---|---|---|---|
| Cut на бит | 0 с | смена мысли внутри главы | `if (t >= cut) drawB()` |
| Cross-fade | 0.35 с | между главами с общей композицией | `alpha = ease(t / 0.35)` |
| Сдвиг | 0.45 с | смена направления движения | `x = lerp(1920, 0, p)` |
| Дип в фон | 0.4 с | вход в дыхание | `alpha = 1 - sin(π·p)` |
| Глитч | 2 кадра | кульминация, один раз на ролик | сдвиг полос на 12–40 px |
| Смена палитры | 0.8 с | граница глав | `lerpColor(a, b, p)` |

Правило: один основной тип на ролик, один «фирменный» — на кульминацию. Пять разных переходов превращают видео в слайд-шоу.

```js
// Палитра главы: акцент смещается, фон и белый остаются
const GRADE = [
  { accent: PALETTE.cyan,    shift: 0 },
  { accent: PALETTE.magenta, shift: 8 },
  { accent: PALETTE.amber,   shift: 16 },
  { accent: PALETTE.cyan,    shift: 24 },
];
const chapterIndex = t => CHAPTERS.reduce((k, c, i) => (t >= c.t0 ? i : k), 0);
const accentAt = t => {
  const i = chapterIndex(t);
  const p = clamp01((t - CHAPTERS[i].t0) / 0.8);
  return mixHex(GRADE[i - 1].accent, GRADE[i].accent, i ? p : 1);
};
const clamp01 = x => Math.min(1, Math.max(0, x));
const mixHex = (a, b, p) => {                 // #rrggbb → #rrggbb
  const A = parseInt(a.slice(1), 16), B = parseInt(b.slice(1), 16);
  const ch = s => Math.round(((A >> s) & 255) * (1 - p) + ((B >> s) & 255) * p);
  return `rgb(${ch(16)},${ch(8)},${ch(0)})`;
};

// Cross-fade двух сцен: обе рисуются в один canvas, прозрачность делится
function crossFade(t, t0, dur, a, b) {
  const p = clamp01((t - t0) / dur);
  if (p <= 0) return a(t);
  if (p >= 1) return b(t);
  const e = 1 - Math.pow(1 - p, 3);
  ctx.save(); ctx.globalAlpha = 1 - e; a(t); ctx.restore();
  ctx.save(); ctx.globalAlpha = e;     b(t); ctx.restore();
}
```

Смена палитры идёт на границе бара, а не на границе сцены: глаз ловит ритм раньше, чем цвет.

## 11.6 Дыхание

Две паузы на 90 с — обязательны. Без них зритель перестаёт различать главы к 60-й секунде.

| Пауза | Время | Длина | Что происходит |
|---|---|---|---|
| Первая | после 2-й главы (44.0–45.5) | 1.5 с | статика, звук в ноль, только дрейф 2 px |
| Вторая | перед callback (76.5–78.0) | 1.5 с | один объект, тёмный фон, пэд −18 дБ |

Требования к паузе:

- Картинка не замирает полностью: дрейф 1–2 px или пульсация alpha 0.02 — иначе кажется, что видео встало.
- Звук уходит в тишину за 0.25 с и возвращается за 0.15 с: резкий вход после тишины работает как удар.
- В паузе не появляется новый текст. Никакого.
- Пауза — не пустой кадр: HUD и линия прогресса остаются.

```js
// Огибающая движения: к концу сцены всё «выдыхает»
const easeOut = t => 1 - Math.pow(1 - t, 3);
const settle = (local, len, d = 0.6) => 1 - easeOut(clamp01((local - (len - d)) / d));

// Пример: объект замедляется к концу главы, но не останавливается
const speed = 1 - 0.85 * (1 - settle(local, len));
const x = 960 + Math.sin(t * 0.7) * 260 * speed;
```

## 11.7 Проверка

| Ограничение | Значение | Как проверить |
|---|---|---|
| Глав | 3–8, не больше 8 | `CHAPTERS.length` |
| Длительность | 60–180 с, не больше 180 | `__meta.duration` |
| Мысль на главу | ровно одна | текст главы ≤ 12 слов |
| Смена сцены | не чаще 1.5 с | число `cut` ≤ `duration / 1.5` |
| Хук | ≤ 3 с | первый текст на 0.2–0.4 с |
| Финал | 3–6 с | последняя сцена в `SCENES` |
| Callback | обязателен после 60 с | сцена с `scene: 'callback'` |
| Паузы | ≥ 2 на 90 с | окна тишины в миксе |

Финальный прогон: собрать контактный лист `fps=2` и разложить 12 листов по 7.5 с. На каждом листе должно быть видно, какая это глава, — по цвету акцента и номеру в HUD. Если по листу нельзя определить главу, связанность потеряна.

Ещё одна проверка — «тест без звука»: выключить аудио и посмотреть целиком. Если смысл читается по картинке, монтаж работает. Если нет — текст в кадре слишком редкий или слишком мелкий, а не звук виноват.
