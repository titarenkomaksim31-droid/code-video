# Тайминг и easing: сетка, удары, камера

Время в ролике задаётся секундами, но живёт на сетке кадров. Позиции и камера считаются от `t` в секундах, easing — от нормализованного `x`; границы событий квантуются к `1 / fps` из `__meta`. Картинка 1920×1080, звук и графика используют один BPM.

## Сетка BPM

`beat = 60 / BPM`, `bar = 4 · beat`, `16-я = beat / 4`. Кадры считаются как `время · fps`; дробное значение означает, что событие попадает между кадрами и должно быть сдвинуто к ближайшему кадру.

| BPM | beat, с | bar, с | 16-я, с | 30 fps: beat / bar / 16 | 60 fps: beat / bar / 16 |
|---:|---:|---:|---:|---|---|
| 90 | 0.6667 | 2.6667 | 0.1667 | 20 / 80 / 5 | 40 / 160 / 10 |
| 100 | 0.6000 | 2.4000 | 0.1500 | 18 / 72 / 4.5 | 36 / 144 / 9 |
| 120 | 0.5000 | 2.0000 | 0.1250 | 15 / 60 / 3.75 | 30 / 120 / 7.5 |
| 128 | 0.4688 | 1.8750 | 0.1172 | 14.0625 / 56.25 / 3.5156 | 28.125 / 112.5 / 7.0313 |

При 120 BPM один бар — ровно 60 кадров при 30 fps. При 100 BPM 16-я равна 4.5 кадра: два удара подряд займут 4 и 5 кадров, если квантовать `floor`, и это заметно на быстрой сетке. При 128 BPM безопаснее 60 fps либо визуальная сетка по 16-м с шагом 3–4 кадра.

## Квантование

`quant(t) = floor(t · fps) / fps`: событие привязывается к номеру кадра, а не к сырому `t`. Иначе `0.499999999` и `0.500000001` могут попасть в разные стороны границы при разных прогонах и разной частоте вызовов.

```js
const FPS = 30;
const EPS = 1e-6;
const frameOf = (t, fps = FPS) => Math.floor(t * fps + EPS);
const quant = (t, fps = FPS) => frameOf(t, fps) / fps;
const frameTime = (i, fps = FPS) => i / fps;
```

Рендерер идёт по `i = 0 … ceil(duration · fps) − 1` и передаёт `__draw(i / fps)`. Превью получает время из транспорта и тоже прогоняет его через `quant`, поэтому удар, переход и вход текста попадают в те же кадры. Интервал сцены — полуинтервал `[from, to)`:

```js
const sceneIndexAt = (t) => {
  const ft = quant(t);
  return scenes.findIndex((s) => ft >= s.from && ft < s.to);
};
```

При 30 fps соседние кадры стоят через 33,33 мс, при 60 — через 16,67 мс. Визуальное событие не может быть точнее одного кадра; аудиособытие в `OfflineAudioContext` может попасть на семпл, но синхронизировать его с картинкой всё равно надо по кадру. Длительность входа в кадрах переводится в секунды: 6 кадров — 0,2 с при 30 fps и 0,1 с при 60.

Границы сцен и ударов назначай сразу на сетке, а не после анимации:

```js
const snapped = (seconds, fps = FPS) => Math.round(seconds * fps) / fps;
const dropAt = snapped(3.0);      // 3.0 при обоих fps
const cutAt = snapped(8.4, 30);   // 8.4; при 60 это 504-й кадр
```

## Библиотека easing

Все функции, кроме `spring`, принимают `x ∈ [0, 1]`; `spring(t)` принимает секунды после старта. `easeOutBack`, `easeOutElastic` и `spring` выходят за 1; для `globalAlpha` результат надо ограничивать `clamp01`, для координаты и масштаба — нет.

| Функция | Формула | Характер |
|---|---|---|
| `linear` | `x` | равномерно; только прогресс-бар, сетка, метроном |
| `easeOutQuad` | `1 − (1 − x)²` | мягкое торможение, быстрый старт |
| `easeOutCubic` | `1 − (1 − x)³` | универсальный вход текста и панели |
| `easeInOutCubic` | `4x³` до 0.5, затем `1 − (−2x + 2)³ / 2` | push-in, растворение, симметричный ход |
| `easeOutQuint` | `1 − (1 − x)⁵` | 80% пути за 27,5% времени; главный объект |
| `easeOutExpo` | `1 − 2⁻¹⁰ˣ`, `x = 1 → 1` | очень резкий вход, быстрый удар |
| `easeInOutExpo` | `2²⁰ˣ⁻¹⁰ / 2` до 0.5, затем `(2 − 2⁻²⁰ˣ⁺¹⁰) / 2` | драматичный старт и финиш |
| `easeOutBack` | `1 + c3(x − 1)³ + s(x − 1)²`, `c3 = s + 1`, `s = 1.4` | overshoot 7,1% при `s = 1.4`, 3,7% при `s = 1.0` |
| `easeOutElastic` | `2⁻¹⁰ˣ sin((10x − 0.75) · 2π/3) + 1` | пик около +35%, 2–3 видимых колебания |
| `spring` | `1 − e⁻ᶻʷᵗ(cos(w_d t) + (ζw/w_d) sin(w_d t))` | физическая пружина при ζ < 1; `t` в секундах после старта |

```js
const clamp01 = (x) => x < 0 ? 0 : x > 1 ? 1 : x;

const ease = {
  linear: (x) => x,
  easeOutQuad: (x) => 1 - (1 - x) ** 2,
  easeOutCubic: (x) => 1 - (1 - x) ** 3,
  easeInOutCubic: (x) => x < 0.5
    ? 4 * x ** 3
    : 1 - (-2 * x + 2) ** 3 / 2,
  easeOutQuint: (x) => 1 - (1 - x) ** 5,
  easeOutExpo: (x) => x === 1 ? 1 : 1 - 2 ** (-10 * x),
  easeInOutExpo: (x) => x === 0 ? 0 : x === 1 ? 1 : x < 0.5
    ? 2 ** (20 * x - 10) / 2
    : (2 - 2 ** (-20 * x + 10)) / 2,
  easeOutBack: (x, s = 1.4) => {
    const c3 = s + 1;
    return 1 + c3 * (x - 1) ** 3 + s * (x - 1) ** 2;
  },
  easeOutElastic: (x) => x === 0 ? 0 : x === 1 ? 1
    : 2 ** (-10 * x) * Math.sin((10 * x - 0.75) * (2 * Math.PI / 3)) + 1,
};

function spring(t, freq = 3, zeta = 0.35) {
  if (t <= 0) return 0;
  const w = 2 * Math.PI * freq;
  const wd = w * Math.sqrt(1 - zeta * zeta);
  return 1 - Math.exp(-zeta * w * t) *
    (Math.cos(wd * t) + (zeta * w / wd) * Math.sin(wd * t));
}
```

`easeOutBack` с `s = 1.4` даёт максимум 1,071, то есть 7,1% overshoot; с `s = 1.0` — 1,037. Для основного входа `spring` с ζ = 0,65–0,8 даёт overshoot 6,8–1,5%. ζ = 0,5 даёт 16,3%, ζ = 0,3 — 37% и три заметных отклонения: это акцент, не основной вход.

## Правила движения

| Правило | Число | Как сделать |
|---|---|---|
| Основной путь | 80% дистанции за 30% времени | `easeOutQuint`: 0,8 достигается при `x = 0,275`; `easeOutCubic` даёт те же 0,8 только при `x = 0,415` |
| Вход | 4–8 кадров: 0,13–0,27 с при 30 fps, 0,07–0,13 с при 60 fps | текст — 6 кадров, крупный объект — 8 кадров |
| Overshoot | +3–8% к цели у основного объекта | `easeOutBack` с `s = 1,0…1,4`; не больше одного overshoot на объект |
| Settle | 2–3 колебания, затем покой | `spring` с ζ = 0,4–0,5 для мелкого акцента; после третьего пика амплитуда < 2% |
| Stagger | 40–80 мс между соседями | при 30 fps это 1,2–2,4 кадра; `start + i * 0,06` |
| Anticipation | 2–4 кадра против движения | сдвиг −3…−6% перед стартом, затем основной easing |

Вход в 4 кадра при 30 fps — 0,133 с: этого достаточно для вспышки, но мало для чтения. Вход в 8 кадров — 0,267 с; после него сразу начинается удержание. Если объект должен читаться, не растягивай вход больше 10 кадров: зритель уже понял кадр, а движение ещё идёт.

Stagger применяется к одинаковым элементам, а не ко всему кадру. Пять строк с шагом 60 мс заканчивают вход через 0,24 с + длительность входа; при шаге 80 мс — через 0,32 с + вход. Больше 0,35 с суммарной задержки группа распадается.

Anticipation — это отрицательный сдвиг перед движением вперёд. Для карточки, которая едет слева в `x = 300`, первые 3 кадра держи `x = 300 − 18` и только потом веди к цели. Сдвиг 18 px — это 6% от 300; больше похоже на ошибку раскладки.

## Удары и BPM

Импульс от beat — экспонента, привязанная к абсолютному времени. Никакого накопления и лерпа: удар должен быть острым в первом кадре.

```js
function pulse(t, bpm = 120, sharpness = 6) {
  const beat = 60 / bpm;
  const phase = ((t % beat) + beat) % beat;   // защита от t < 0
  return Math.exp(-sharpness * phase);
}
```

| Sharpness | 0 с после удара | 0,05 с | 0,10 с | 0,25 с | 0,50 с |
|---:|---:|---:|---:|---:|---:|
| 3 | 1.000 | 0.861 | 0.741 | 0.472 | 0.223 |
| 6 | 1.000 | 0.741 | 0.549 | 0.223 | 0.050 |
| 10 | 1.000 | 0.607 | 0.368 | 0.082 | 0.007 |

`sharpness` — в 1/с. При 120 BPM и `sharpness = 6` к следующему удару остаётся 0,050, то есть хвост почти исчез. При `sharpness = 3` остаётся 0,223 — пульс «дышит» через границу beat; это подходит для фона. `sharpness = 10` — для монтажных ударов и вспышек.

```js
const p = pulse(t, 120, 8);
const scale = 1 + 0.06 * p;                 // +6% в момент удара
const dy = -12 * p;                         // подъём на 12 px
const alpha = 0.65 + 0.35 * p;              // яркость
const glow = 0.25 + 0.75 * p;               // альфа свечения
```

Одиночный удар считается без beat-цикла:

```js
const hit = (t, at, sharpness = 12) =>
  t < at ? 0 : Math.exp(-sharpness * (t - at));
```

`hit(t, 3.0, 12)` при 30 fps: 1,0 в кадре 90, 0,670 через кадр, 0,449 через два, 0,008 через 0,4 с. Flash, тряска и звук ставятся в один кадр; задержка между пиками > 1 кадра читается как рассинхрон.

## Камера

Push-in 1,0 → 1,06 за 4 секунды. Масштаб вокруг центра кадра; на 1920 px это добавляет 115,2 px по ширине, по 57,6 px с каждой стороны. Текст держи в безопасном поле 64 px от края.

```js
const z = 1 + 0.06 * ease.easeInOutCubic(clamp01(t / 4));
```

Parallax: фон 0.2, средний план 0.5, передний 1.0. Смещение камеры — 20–30 px, иначе передний план уезжает из кадра.

```js
const cam = { x: 26 * Math.sin(t * 0.7), y: 12 * Math.sin(t * 0.53 + 1.1) };
function plane(k, draw) {
  ctx.save();
  ctx.translate(-cam.x * k, -cam.y * k);
  draw();
  ctx.restore();
}
plane(0.2, drawBackground);
plane(0.5, drawMid);
plane(1.0, drawForeground);
```

Тряска с затуханием 0,88 за кадр. В бесстатусном `draw` это степень от номера кадра после удара, а не переменная, которую уменьшают на каждом вызове:

```js
function shakeAt(t, at, fps = FPS, amp = 20) {
  const df = Math.floor((t - at) * fps);
  if (df < 0) return { x: 0, y: 0, rot: 0 };
  const a = amp * Math.pow(0.88, df);
  return {
    x: a * Math.sin((df + 1) * 1.7),
    y: a * Math.sin((df + 1) * 2.3 + 0.9),
    rot: a * 0.0004 * Math.sin((df + 1) * 1.1),
  };
}
```

Амплитуда падает до 1% через 36 кадров: 1,2 с при 30 fps и 0,6 с при 60 fps. Передавай в `shakeAt` fps из `__meta`, а не фактический rAF, иначе превью и рендер разойдутся по длительности тряски. Hz здесь не нужен: шаг дискретный, каждый кадр — новое значение.

Handheld — сумма трёх синусов с иррациональными частотами. За 20–90 с они не складываются в заметный повтор:

```js
function handheld(t) {
  const x = 2.4 * Math.sin(t * Math.PI * Math.SQRT2)
          + 1.3 * Math.sin(t * Math.PI * Math.sqrt(3) + 1.7)
          + 0.6 * Math.sin(t * Math.PI * Math.sqrt(5) + 0.4);
  const y = 1.8 * Math.sin(t * Math.PI * Math.sqrt(2) + 2.2)
          + 0.9 * Math.sin(t * Math.PI * Math.sqrt(7) + 0.6)
          + 0.4 * Math.sin(t * Math.PI * Math.sqrt(11) + 1.1);
  return { x, y };
}
```

Суммарная амплитуда x — до 4,3 px, y — до 3,1 px. Частоты 0,71, 0,87 и 1,12 Hz для x; это микродвижение, не «камера в руках». Применяй после push-in и shake, но до HUD:

```js
const s = shakeAt(t, 2.0);
const h = handheld(t);
const push = 1 + 0.06 * ease.easeInOutCubic(clamp01(t / 4));
ctx.save();
ctx.translate(W / 2 + s.x + h.x, H / 2 + s.y + h.y);
ctx.rotate(s.rot);
ctx.scale(push, push);
ctx.translate(-W / 2, -H / 2);
drawWorld(t);                               // подписи сюда не входят
ctx.restore();
```

`paint()` из 01 сбрасывает матрицу перед сценой. Если используешь его, применяй камеру внутри слоя после сброса, а HUD и переходные буферы собирай без камеры.

## Тайминги текста

| Фаза | Кадры (30 / 60) | 30 fps | 60 fps | Ограничение |
|---|---:|---:|---:|---|
| Появление | 6–10 | 0,20–0,33 с | 0,10–0,17 с | 6 кадров для строки, 10 для заголовка |
| Удержание | 45–60 / 90–120 | 1,5–2,0 с | 1,5–2,0 с | ключевая строка — верхняя граница |
| Уход | 4–6 | 0,13–0,20 с | 0,07–0,10 с | без ухода в ноль под следующим объектом |

Скорость чтения — 15–17 знаков в секунду. Строка из 28 знаков требует 1,65–1,87 с удержания; 60 знаков — 3,5–4,0 с. При 120 BPM удержание 1,5–2,0 с — это 3–4 beat.

```js
function caption(t, inAt, outAt) {
  const kin = ease.easeOutCubic(clamp01((quant(t) - inAt) / (7 / FPS)));
  const kout = ease.easeOutCubic(clamp01((quant(t) - outAt) / (5 / FPS)));
  return {
    alpha: clamp01(kin * (1 - kout)),
    y: 18 * (1 - kin) - 8 * kout,
  };
}
```

Текст не размывается и не масштабируется от 0: при 30 fps это читается как дрожание. Анимируй `alpha`, `y` на 12–24 px или маску по ширине. Первая строка входит за 6 кадров, вторая начинается через 60–80 мс, обе уходят одновременно, если это один смысловой блок.

## Анти-паттерны

| Ошибка | Признак | Замена |
|---|---|---|
| Всё линейно | объект ползёт с постоянной скоростью, исчезает без торможения | основной вход — `easeOutQuint` или `easeOutExpo`; `linear` — только прогресс и сетка |
| Всё стартует одновременно | группа из 5 элементов читается как один блок | stagger 40–80 мс, суммарная задержка ≤ 0,35 с |
| Слишком медленно | вход > 10 кадров, удержание < 1,5 с | вход 4–8 кадров, удержание 1,5–2,0 с |
| Слишком быстро | вход < 3 кадров, уход < 3 кадров | вход 6 кадров, уход 5 кадров при 30 fps |
| Движение без причины | объект качается всё время, хотя не входит и не акцентируется | оставить покой; ambient-дрожание ≤ 4 px и только на фоне |
| Overshoot на всём | каждая карточка и каждая буква пружинят | overshoot 3–8% только у одного главного объекта на beat |

## Финальный сниппет

Мини-сцена: тайминг-хелпер `at`, пять полос входят со stagger, пульсируют по 120 BPM, пружина даёт overshoot. Код рабочий при наличии `<canvas id="c" width="1920" height="1080">`.

```js
const FPS = 30, W = 1920, H = 1080;
const ctx = document.querySelector('#c').getContext('2d', { alpha: false });
const C = { bg: '#05060d', cyan: '#4ff0ff', white: '#f4f7ff' };

const q = (t) => Math.floor(t * FPS + 1e-6) / FPS;
const clamp01 = (x) => x < 0 ? 0 : x > 1 ? 1 : x;
const easeOutCubic = (x) => 1 - (1 - x) ** 3;
const at = (t, from, dur) => clamp01((q(t) - from) / dur); // окно события

function stagger(t, from, i, step = 0.06, dur = 0.24) {
  return at(t, from + i * step, dur);
}

function pulse(t, bpm = 120, sharpness = 8) {
  const beat = 60 / bpm;
  const phase = ((t % beat) + beat) % beat;
  return Math.exp(-sharpness * phase);
}

function spring(t, freq = 3.2, zeta = 0.65) {
  if (t <= 0) return 0;
  const w = 2 * Math.PI * freq;
  const wd = w * Math.sqrt(1 - zeta * zeta);
  return 1 - Math.exp(-zeta * w * t) *
    (Math.cos(wd * t) + (zeta * w / wd) * Math.sin(wd * t));
}

function draw(t) {
  ctx.setTransform(1, 0, 0, 1, 0, 0);
  ctx.globalAlpha = 1;
  ctx.globalCompositeOperation = 'source-over';
  ctx.fillStyle = C.bg;
  ctx.fillRect(0, 0, W, H);

  const hit = pulse(t, 120, 8);
  ctx.globalAlpha = 0.25 + 0.75 * hit;
  ctx.fillStyle = C.cyan;
  ctx.fillRect(220, 360, 8, 520);

  for (let i = 0; i < 5; i++) {
    const start = 0.6 + i * 0.06;
    const e = stagger(t, 0.6, i, 0.06, 0.24);
    const s = spring(Math.max(0, q(t) - start), 3.2, 0.65);
    const y = 430 + i * 90 + 56 * (1 - s);      // выброс около 4 px
    ctx.globalAlpha = easeOutCubic(e) * (0.65 + 0.35 * hit);
    ctx.fillStyle = i === 0 ? C.cyan : C.white;
    ctx.fillRect(260, y, 760 * easeOutCubic(e), 5);
  }

  ctx.globalAlpha = 1;
}

window.__meta = { duration: 20, fps: FPS, width: W, height: H, title: 'timing demo' };
window.__draw = draw;
draw(0);
window.__ready = true;
```
