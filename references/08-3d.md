# 3D на three.js: свет, шейдеры и детерминированный рендер
3D добавляет к ролику камеру, глубину и материалы, но стоит 100–300 мс инициализации и 2–5× кода. Ниже — минимальный набор для 1920×1080, 30 fps, BPM 120, без HDR-файлов и внешних текстур: env-карта рисуется в canvas, геометрия генерируется, частицы считаются шейдером. Всё время приходит в `render(t)`, системные часы не используются.
```js
const W = 1920, H = 1080, BPM = 120, BEAT = 60 / BPM; // 0.5 с
```
## Когда 3D оправдано
| Задача | 3D | 2D | Решение |
|---|---|---|---|
| Движение камеры, параллакс | dolly/orbit даёт глубину бесплатно | transform/scale слоёв | 3D, если камера проходит ≥1 диаметр сцены |
| Металл, стекло, rim-light | PBR + env-карта | градиенты и маски | 3D при двух и более материалах |
| Заголовки и цифры | текст теряет кромку, дорогой bloom | Canvas 2D/HTML-оверлей | 2D поверх готового 3D |
| Схемы, графики, таймлайн | перспектива искажает значения | точные оси и подписи | 2D |
| 500+ однотипных объектов | `InstancedMesh`, 1 draw call | 500 draw calls в Canvas | 3D |
| 20–90 с, много итераций | 100–300 мс init и отладка шейдеров | мгновенный перезапуск | 2D для черновика |
Правило: 3D выигрывает, если есть хотя бы два пункта — камера, свет/материал, реальный объём. Титры, логотип и подписи остаются 2D-слоем: 3D-текст на 1080p требует SDF-атласа и всё равно уступает по читаемости. Гибрид — 3D-фон сцены и 2D-титры через второй canvas или CSS.
## Подключение three.js
| Путь | Файлы | Когда | Цена |
|---|---|---|---|
| CDN import map | 0 локальных | черновик, есть сеть | 680 КБ загрузки, кеш браузера |
| локальный модуль | 2+ файла | разработка, addons | нужен HTTP-сервер, `file://` заблокирован |
| инлайн в HTML | 1 HTML | финальный ролик, offline | 750–900 КБ HTML |
CDN с фиксированной версией r170 и addons:
```html

{"imports":{
  "three":"https://cdn.jsdelivr.net/npm/three@0.170.0/build/three.module.min.js",
  "three/addons/":"https://cdn.jsdelivr.net/npm/three@0.170.0/examples/jsm/"

</script>
<script type="module">
import * as THREE from 'three';
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
</script>
```
Локальный вариант: те же ключи import map, но `"three":"./three.module.min.js"` и `"three/addons/":"./jsm/"`. Запускайте через HTTP: ES-модули с `file://` не загружаются из-за CORS. Для одного HTML берите инлайн-сборку: CDN оставляет сетевую зависимость, а локальный `jsm/` — второй файл. В финале не должно быть ни того, ни другого.
## Инициализация
```js
const canvas = document.querySelector('#stage');
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: false, powerPreference: 'high-performance' });
renderer.setPixelRatio(1);                 // DPR не трогаем
renderer.setSize(W, H, false);            // буфер ровно 1920×1080
renderer.outputColorSpace = THREE.SRGBColorSpace; renderer.toneMapping = THREE.ACESFilmicToneMapping; renderer.toneMappingExposure = 1.1;
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
renderer.setClearColor(0x05060d, 1);
const scene = new THREE.Scene();
scene.background = new THREE.Color(0x05060d);
scene.fog = new THREE.FogExp2(0x05060d, 0.035);
const camera = new THREE.PerspectiveCamera(40, W / H, 0.1, 100);
camera.position.set(0, 1.4, 7);
```
| Параметр | Значение | Причина |
|---|---|---|
| fov | 40° (35–50) | 35° = телеобъектив и плоская глубина; 50° = широкий угол |
| near / far | 0.1 / 100 | при 30–50° и сцене 5–10 м хватает; меньше near — точнее depth |
| pixelRatio | 1 | 1920×1080 уже целевое; DPR 2 = 4× пикселей |
| toneMapping | ACESFilmic | сохраняет блики cyan/magenta |
| exposure | 1.0–1.3 | компенсация LDR env-карты |
| antialias | true | в composer MSAA задаётся у render target |
CSS задаёт `width:100vw; height:56.25vw; max-height:100vh; object-fit:contain`; canvas-атрибуты остаются 1920×1080. Не пересчитывайте размер по `window.resize`.
## Свет и env-карта
| Свет | Цвет | Интенсивность | Позиция | Роль |
|---|---|---|---|---|
| key `DirectionalLight` | `#f4f7ff` | 2.0 | (4, 6, 5) | форма и тени |
| rim `DirectionalLight` | `#4ff0ff` | 1.6 | (−5, 2, −4) | контур cyan сзади |
| fill `DirectionalLight` | `#ff3fa4` | 0.6 | (0, −2, 3) | магента в тенях |
| `HemisphereLight` | sky `#4ff0ff`, ground `#05060d` | 0.25 | — | заполнение без теней |
| accent `PointLight` | `#ffd166` | 40 кд | (2, 1, 2) | блик на металле, decay 2 |

r160+ считает свет в физических единицах: для point/spot интенсивность в канделах, distance и decay влияют; для directional — условные люксы. Key включает `castShadow`, mapSize 1024×1024, bias −0.0004, near 0.5, far 30; rim и fill тени не отбрасывают.
```js
function makeEnv(renderer) {
  const c = document.createElement('canvas'); c.width = 1024; c.height = 512;
  const x = c.getContext('2d');
  const grad = x.createLinearGradient(0, 0, 0, 512);
  grad.addColorStop(0, '#0c2a38'); grad.addColorStop(0.45, '#05060d'); grad.addColorStop(1, '#1b0714');
  x.fillStyle = grad; x.fillRect(0, 0, 1024, 512);
  const glow = (cx, cy, r, color) => {
    const g = x.createRadialGradient(cx, cy, 0, cx, cy, r);
    g.addColorStop(0, color); g.addColorStop(1, 'rgba(0,0,0,0)');
    x.fillStyle = g; x.fillRect(cx - r, cy - r, r * 2, r * 2);
  };
  glow(250, 120, 240, 'rgba(79,240,255,0.95)');
  glow(760, 160, 260, 'rgba(255,63,164,0.8)');
  const tex = new THREE.CanvasTexture(c);
  tex.mapping = THREE.EquirectangularReflectionMapping; tex.colorSpace = THREE.SRGBColorSpace;
  const pmrem = new THREE.PMREMGenerator(renderer);
  pmrem.compileEquirectangularShader();
  const env = pmrem.fromEquirectangular(tex).texture;
  tex.dispose(); pmrem.dispose();
  return env;
}
scene.environment = makeEnv(renderer);
scene.environmentIntensity = 0.9;
```
`PMREMGenerator` строит mip-chain для roughness; `fromEquirectangular` занимает 5–20 мс. Canvas даёт LDR 0–1, поэтому яркие блики компенсируются `toneMappingExposure`, а не значениями >1.
## Процедурная геометрия
```js
function seeded(seed) {
  return () => {
    seed = seed + 0x6d2b79f5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}
function makeArtifact() {
  const rnd = seeded(0xc0ffee), group = new THREE.Group();
  const coreGeo = new THREE.IcosahedronGeometry(1.2, 5);
  const pos = coreGeo.attributes.position;
  for (let i = 0; i < pos.count; i++) {
    const v = new THREE.Vector3().fromBufferAttribute(pos, i);
    v.multiplyScalar(1 + 0.14 * Math.sin(v.x * 3.1 + v.y * 2.3) * Math.cos(v.z * 2.7));
    pos.setXYZ(i, v.x, v.y, v.z);
  }
  coreGeo.computeVertexNormals();
  const core = new THREE.Mesh(coreGeo, new THREE.MeshStandardMaterial({ color: 0x0b2733, metalness: 0.85, roughness: 0.24, emissive: 0x4ff0ff, emissiveIntensity: 0.1 }));
  const shell = new THREE.Mesh(new THREE.IcosahedronGeometry(1.34, 2),
    new THREE.MeshBasicMaterial({ color: 0x4ff0ff, wireframe: true, transparent: true, opacity: 0.16 }));
  const knot = new THREE.Mesh(new THREE.TorusKnotGeometry(1.9, 0.018, 180, 8, 2, 3),
    new THREE.MeshBasicMaterial({ color: 0xff3fa4 }));
  knot.rotation.x = Math.PI / 2.6;
  const shards = new THREE.InstancedMesh(new THREE.IcosahedronGeometry(0.045, 0),
    new THREE.MeshStandardMaterial({ color: 0x4ff0ff, emissive: 0x4ff0ff, emissiveIntensity: 0.35 }), 256);
  const m = new THREE.Matrix4(), q = new THREE.Quaternion(), s = new THREE.Vector3(), p = new THREE.Vector3();
  for (let i = 0; i < 256; i++) {
    p.set(rnd() - 0.5, rnd() - 0.5, rnd() - 0.5).normalize().multiplyScalar(2.1 + rnd() * 2.4);
    q.setFromEuler(new THREE.Euler(rnd() * 6.28, rnd() * 6.28, rnd() * 6.28));
    s.setScalar(0.5 + rnd() * 1.6);
    shards.setMatrixAt(i, m.compose(p, q, s));
  }
  shards.instanceMatrix.needsUpdate = true;
  group.add(core, shell, knot, shards);
  return group;
}
scene.add(makeArtifact());
```
`IcosahedronGeometry(1.2, 5)` — 20 480 треугольников; смещение по формуле от позиции не рвёт грани. `InstancedMesh` на 256 осколков — один draw call. Объект = группа из ядра, каркаса, torus-knot и облака; один примитив с одной шкалой не читается как объект.

Своя геометрия из массива:
```js
const ribbon = new THREE.BufferGeometry();
ribbon.setAttribute('position', new THREE.Float32BufferAttribute([-2,0,0, 2,0,0, 2,0.16,0.5, -2,0.16,0.5], 3));
ribbon.setIndex([0,1,2, 0,2,3]);
ribbon.computeVertexNormals();
```
Индексы обязательны для полос; `computeVertexNormals()` даст освещение, а UV не нужен, если материал без текстуры.
## Шейдеры
```js
const material = new THREE.ShaderMaterial({
  uniforms: { uTime: { value: 0 }, uAmp: { value: 0.16 }, uColorA: { value: new THREE.Color('#07131c') }, uColorB: { value: new THREE.Color('#4ff0ff') }, uResolution: { value: new THREE.Vector2(W, H) } },
  vertexShader: /* glsl */`
    uniform float uTime, uAmp;
    varying vec3 vN, vView;
    vec3 mod289(vec3 x){ return x - floor(x * (1.0 / 289.0)) * 289.0; }
    vec4 mod289(vec4 x){ return x - floor(x * (1.0 / 289.0)) * 289.0; }
    vec4 permute(vec4 x){ return mod289(((x * 34.0) + 1.0) * x); }
    vec4 taylorInvSqrt(vec4 r){ return 1.79284291400159 - 0.85373472095314 * r; }
    float snoise(vec3 v) {
      const vec2 C = vec2(1.0 / 6.0, 1.0 / 3.0); const vec4 D = vec4(0.0, 0.5, 1.0, 2.0);
      vec3 i = floor(v + dot(v, C.yyy)); vec3 x0 = v - i + dot(i, C.xxx);
      vec3 g = step(x0.yzx, x0.xyz); vec3 l = 1.0 - g;
      vec3 i1 = min(g.xyz, l.zxy), i2 = max(g.xyz, l.zxy);
      vec3 x1 = x0 - i1 + C.xxx, x2 = x0 - i2 + C.yyy, x3 = x0 - D.yyy;
      i = mod289(i);
      vec4 p = permute(permute(permute(
        i.z + vec4(0.0, i1.z, i2.z, 1.0)) + i.y + vec4(0.0, i1.y, i2.y, 1.0)) + i.x + vec4(0.0, i1.x, i2.x, 1.0));
      float n_ = 0.142857142857; vec3 ns = n_ * D.wyz - D.xzx;
      vec4 j = p - 49.0 * floor(p * ns.z * ns.z); vec4 x_ = floor(j * ns.z); vec4 y_ = floor(j - 7.0 * x_);
      vec4 x = x_ * ns.x + ns.yyyy; vec4 y = y_ * ns.x + ns.yyyy; vec4 h = 1.0 - abs(x) - abs(y);
      vec4 b0 = vec4(x.xy, y.xy); vec4 b1 = vec4(x.zw, y.zw);
      vec4 s0 = floor(b0) * 2.0 + 1.0; vec4 s1 = floor(b1) * 2.0 + 1.0; vec4 sh = -step(h, vec4(0.0));
      vec4 a0 = b0.xzyw + s0.xzyw * sh.xxyy; vec4 a1 = b1.xzyw + s1.xzyw * sh.zzww;
      vec3 p0 = vec3(a0.xy, h.x), p1 = vec3(a0.zw, h.y), p2 = vec3(a1.xy, h.z), p3 = vec3(a1.zw, h.w);
      vec4 norm = taylorInvSqrt(vec4(dot(p0,p0), dot(p1,p1), dot(p2,p2), dot(p3,p3)));
      p0 *= norm.x; p1 *= norm.y; p2 *= norm.z; p3 *= norm.w;
      vec4 m = max(0.6 - vec4(dot(x0,x0), dot(x1,x1), dot(x2,x2), dot(x3,x3)), 0.0); m = m * m;
      return 42.0 * dot(m * m, vec4(dot(p0,x0), dot(p1,x1), dot(p2,x2), dot(p3,x3)));
    }
    void main() {
      float n = snoise(position * 1.4 + vec3(0.0, 0.0, uTime * 0.25));
      vec3 p = position + normal * n * uAmp;
      vec4 mv = modelViewMatrix * vec4(p, 1.0);
      vN = normalize(normalMatrix * normal); vView = -mv.xyz;
      gl_Position = projectionMatrix * mv;
    }`,
  fragmentShader: /* glsl */`
    uniform vec3 uColorA, uColorB; uniform vec2 uResolution;
    varying vec3 vN, vView;
    void main() {
      float f = pow(1.0 - abs(dot(normalize(vN), normalize(vView))), 3.0);
      vec3 col = mix(uColorA, uColorB, f) + uColorB * pow(f, 1.5) * 0.8;
      float g = fract(sin(dot(gl_FragCoord.xy / uResolution, vec2(12.9898, 78.233))) * 43758.5453) - 0.5;
      col += g * 0.02; gl_FragColor = vec4(col, 1.0);
    }`
});
```
`fresnel = pow(1 − |dot(N,V)|, 3)` даёт обводку по касательной; внутри — `uColorA`, на контуре — cyan. `uAmp 0.16` при радиусе 1.2 не рвёт силуэт. Симплекс возвращает −1…1; при `uTime` шум «дышит» на 0.25 Гц. `uResolution` задаёт масштаб пиксельного зерна. Для прямого рендера без composer добавьте в конец фрагмента `#include <tonemapping_fragment>` и `#include <colorspace_fragment>`; с `OutputPass` этого делать нельзя — будет двойная гамма.
## Частицы 20 000
```js
const COUNT = 20000, rnd = seeded(42);
const pos = new Float32Array(COUNT * 3), size = new Float32Array(COUNT), seed = new Float32Array(COUNT);
for (let i = 0; i < COUNT; i++) {
  const r = 2.4 + rnd() * 4.2, a = rnd() * Math.PI * 2, z = rnd() * 2 - 1, s = Math.sqrt(1 - z * z);
  pos[i*3] = Math.cos(a) * s * r; pos[i*3+1] = z * r * 0.55; pos[i*3+2] = Math.sin(a) * s * r;
  size[i] = 0.5 + rnd() * 2.2; seed[i] = rnd();
}
const pg = new THREE.BufferGeometry();
pg.setAttribute('position', new THREE.BufferAttribute(pos, 3)); pg.setAttribute('size', new THREE.BufferAttribute(size, 1)); pg.setAttribute('seed', new THREE.BufferAttribute(seed, 1));
const pmat = new THREE.ShaderMaterial({
  uniforms: { uTime: { value: 0 }, uColor: { value: new THREE.Color('#4ff0ff') } },
  vertexShader: `uniform float uTime; attribute float size, seed; varying float vA;
    void main() {
      vec3 p = position; float a = uTime * (0.1 + seed * 0.12) + seed * 6.283;
      p.xz = mat2(cos(a), -sin(a), sin(a), cos(a)) * p.xz;
      p.y += sin(uTime * 0.7 + seed * 20.0) * 0.15;
      vec4 mv = modelViewMatrix * vec4(p, 1.0);
      gl_PointSize = clamp(size * (12.0 / -mv.z), 1.0, 12.0);
      gl_Position = projectionMatrix * mv; vA = 0.35 + seed * 0.65;
    }`,
  fragmentShader: `uniform vec3 uColor; varying float vA;
    void main() {
      float d = length(gl_PointCoord - 0.5); if (d > 0.5) discard;
      gl_FragColor = vec4(uColor, smoothstep(0.5, 0.0, d) * vA);
    }`,
  transparent: true, depthWrite: false, blending: THREE.AdditiveBlending
});
const points = new THREE.Points(pg, pmat); points.frustumCulled = false; scene.add(points);
```
`gl_PointSize = size · 12 / −mv.z` — sizeAttenuation вручную: size 1 на дистанции 6 м даёт 2 px, на 1.5 м — 8 px, clamp 12. Аддитивный блендинг требует `depthWrite:false`, иначе частицы перекрывают друг друга чёрными квадратами. Один draw call, 20 000 вершин, без CPU-обновлений.
## Пост-обработка
```js
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { UnrealBloomPass } from 'three/addons/postprocessing/UnrealBloomPass.js';
import { OutputPass } from 'three/addons/postprocessing/OutputPass.js';
import { ShaderPass } from 'three/addons/postprocessing/ShaderPass.js';
const rt = new THREE.WebGLRenderTarget(W, H, { type: THREE.HalfFloatType, samples: 4 });
const composer = new EffectComposer(renderer, rt);
composer.setPixelRatio(1); composer.setSize(W, H);
composer.addPass(new RenderPass(scene, camera));
composer.addPass(new UnrealBloomPass(new THREE.Vector2(W, H), 0.6, 0.4, 0.85));
composer.addPass(new OutputPass());
const grain = new ShaderPass({
  uniforms: { tDiffuse: { value: null }, uTime: { value: 0 }, uAmount: { value: 0.035 } },
  vertexShader: `varying vec2 vUv; void main(){ vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
  fragmentShader: `uniform sampler2D tDiffuse; uniform float uTime, uAmount; varying vec2 vUv;
    float hash(vec2 p) { p = fract(p * vec2(123.34, 456.21)); p += dot(p, p + 45.32); return fract(p.x * p.y); }
    void main() {
      vec4 c = texture2D(tDiffuse, vUv);
      float n = hash(gl_FragCoord.xy + uTime * vec2(17.0, 31.0)) - 0.5;
      gl_FragColor = vec4(c.rgb + n * uAmount, 1.0);
    }`
});
composer.addPass(grain);
```
Порядок: RenderPass → UnrealBloomPass(0.6, 0.4, 0.85) → OutputPass → grain. Bloom работает в линейном HDR (`HalfFloatType`), OutputPass делает ACES и sRGB один раз, зерно добавляется уже в дисплейном пространстве. `samples: 4` включает MSAA в composer; `renderer.antialias` на render target не действует. `grain.uniforms.uTime.value = t` в `render(t)`.
## Камера
```js
const pulse = t => Math.exp(-7 * ((t % BEAT) / BEAT)); // 1 на beat, спад к 0.5 с
function updateCamera(t) {
  const az = 0.35 + t * 0.14, dist = 6.8 - 1.6 * Math.min(1, t / 18) ** 2, p = pulse(t);
  camera.position.set(Math.sin(az) * dist, 1.5 + Math.sin(t * 0.35) * 0.25 + p * 0.05, Math.cos(az) * dist);
  camera.position.x += 0.016 * p * Math.sin(t * 137.1);
  camera.position.y += 0.016 * p * Math.sin(t * 151.7);
  camera.lookAt(0, 0.1, 0);
}
```
`dist` — dolly: 6.8 → 5.2 м за 18 с по `t²`. `az` — orbit 0.14 рад/с (полный оборот 45 с). `pulse` даёт 0.016 м дрожания на beat (≈0.2% кадра) и детерминирована от `t`. `lookAt` вызывайте после shake, иначе направление сдвинется.
## Детерминизм
- `window.__draw(t)` — чистая функция: при одинаковом `t` одинаковый кадр, порядок вызовов не важен. Никакого накопления `rot += speed` внутри draw.
- Все `Math.random()` заменяются на `seeded(seed)` при инициализации; в кадре — только `uTime = t` и формулы от `t`.
- Запрещены `Date.now()`, `performance.now()`, `requestAnimationFrame` внутри сцены. rAF — только внешний плеер, который передаёт `t`.
- Сначала `renderer.compile(scene, camera)` и пробный кадр, затем `window.__ready = true`. Иначе первый кадр записи включает компиляцию шейдеров.
- Рендер-луп захвата считает кадры, а не секунды: `for (let f=0; f<duration*fps; f++) __draw(f/fps)`.
```js
window.__meta = { duration: 24, fps: 30, width: 1920, height: 1080, title: 'Orbit' };
window.__draw = t => {
  points.material.uniforms.uTime.value = t;
  grain.uniforms.uTime.value = t;
  updateCamera(t);
  composer.render();
};
renderer.compile(scene, camera); window.__draw(0);
window.__ready = true;
```
## Производительность
| Метрика | 30 fps (33.3 мс) | 60 fps (16.7 мс) |
|---|---|---|
| draw calls | ≤80, цель 10–30 | ≤40 |
| треугольники | ≤300 000 | ≤150 000 |
| частицы | 20 000 при точке ≤8 px | 10 000 или без bloom |
| bloom | 1 проход, 0.6/0.4/0.85 | half-res внутренние mip |
| pixelRatio | 1 | 1 |
| тени | 1 карта 1024, статичная | 1 карта 1024 |
| JS на кадр | <8 мс | <4 мс |

20 000 аддитивных точек при среднем размере 4 px — около 0.32 млн фрагментов, это дешевле одного полноэкранного bloom. При 12 px и 20 000 точек — 2.9 млн фрагментов, начинается fill-rate предел. Для замера включите `renderer.info.autoReset=false`, вызовите `reset()` перед `composer.render()` и читайте `calls` после: цель ≤80. В headless Chrome без GPU рендерер может уйти в SwiftShader: определите его по `WEBGL_debug_renderer_info.UNMASKED_RENDERER_WEBGL` и при software-рендере снизьте частицы до 8 000, отключите тени и bloom. Полный кадр 1080p с 20k частиц и bloom на дискретной карте — 6–12 мс; на встроенной — 15–25 мс, 30 fps впритык.
## Инлайн three.js
Вес: `three.module.min.js` r170 ≈ 680 КБ (≈170 КБ gzip), addons для bloom/render/output/shader ≈ 40 КБ, сцена 15–30 КБ. Итоговый один HTML — 730–850 КБ; base64 добавляет 33% (≈1 МБ) и медленнее парсится, поэтому вставляйте исходный JS текстом.

Способ 1 — только ядро, без addons:
```html
<script id="three-src" type="text/plain">/* содержимое three.module.min.js */</script>
<script type="module">
const src = document.getElementById('three-src').textContent;
const THREE = await import(URL.createObjectURL(new Blob([src], { type: 'text/javascript' })));
// ниже: сцена, render(t) и window.__ready
</script>
```
`type="text/plain"` не исполняет код; Blob-URL грузит ESM с экспортами. Если в исходнике встретится `</script>`, замените на `<\/script>`. Addons так не подключить: их `import ... from 'three'` не разрешится в Blob.

Способ 2 — финальная сборка с addons (рекомендуется). Node 24:
```js
// app.js: import * as THREE from 'three'; import { EffectComposer } ...
// npx esbuild app.js --bundle --minify --format=iife --target=chrome120 --outfile=app.bundle.js
```
Затем вставьте содержимое `app.bundle.js` в `<script>` одного HTML. В бандле нет import map и сетевых запросов, `file://` работает, дерево шейкеров esbuild выкидывает неиспользуемые модули. Минифицируйте только JS: GLSL-строки не трогайте, имена uniform и `#include` должны совпадать. Source maps не встраивайте. `window.__meta`, `window.__draw`, `window.__ready` выставляются после создания composer и компиляции.
